# Justnano Website V2

Static product showcase website for GitHub Pages.

## Upload to GitHub
Upload the contents of this folder to the root of the `justnano-website` repository. Do not upload the outer folder itself.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Products
Edit the `products` list in `script.js` to add or update products and Amazon links.

## Custom domain
Add the custom domain only after the GitHub Pages test URL works. DNS and Alibaba Mail records will be handled separately.
